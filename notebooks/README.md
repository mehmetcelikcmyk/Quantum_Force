# 🧪 Notebooks (Deneme ve Analiz) Klasörü

Bu klasör, ekibin Ar-Ge alanıdır. Kodu ana projeye aktarmadan önce yaptığımız tüm veri analizleri, Qiskit/D-Wave denemeleri, grafik çizimleri ve algoritma testleri Jupyter Notebook (`.ipynb`) formatında burada yer alır.

## 🛠 Çalışma Kuralları
1.  **İsimlendirme Standartı:** Karmaşayı önlemek için notebook isimlerinizi şu formatta başlatın: `01_isim_konu.ipynb` (Örn: `01_mehmet_veri_analizi.ipynb`, `02_ahmet_qiskit_deneme.ipynb`).
2.  **Temiz Kod:** Notebook içinde çalışan kod bloklarının yanına mutlaka ne yaptığınıza dair ufak açıklamalar yazın.
3.  **Kalıcı Kodlar:** Buradaki denemelerde başarılı olan ve çalışan algoritmik fonksiyonlar, daha sonra `src/` klasöründeki asıl Python dosyalarına taşınacaktır.
