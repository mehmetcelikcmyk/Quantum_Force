# 📑 Raporlar ve Taslaklar Klasörü

Bu klasör, jüriye sunulmak üzere hazırlanan resmi proje raporlarını (DOCX ve PDF formatlarında) ve taslak dökümleri barındırır.

## 📁 Dosyalar

* **`proje_raporu.docx`:** Detaylı akademik taslak formatında hazırlanan rapor dosyası.
* **`proje_raporu.pdf`:** PDF formatında rapor dosyası.
