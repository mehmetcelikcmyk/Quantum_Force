# 🖼️ Görseller Klasörü

Bu klasör, raporda ve sunumlarda kullanılan kuantum devre şemalarını, karşılaştırma sütun grafiklerini ve kuantum çekirdek sıcaklık haritalarını barındırır.

## 📁 Dosyalar
* **`model_comparison.png`:** Klasik modeller ile Kuantum SVM (QSVM) modelinin performans karşılaştırma sütun grafiği.
* **`quantum_kernel_heatmap.png`:** İlk 50x50 veri örneği arasındaki benzerliği gösteren Kuantum Çekirdek Matrisi (Fidelity) sıcaklık haritası.
