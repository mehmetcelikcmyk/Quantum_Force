# 🧪 Notebooks (Deneme ve Analiz) Klasörü

Bu klasör, projenin araştırma, geliştirme ve veri analiz alanıdır. Algoritmaların test edilmesi, kuantum devrelerinin doğrulanması ve görsel sonuçların incelenmesi Jupyter Notebook formatında bu klasör altında yürütülür.

## 📁 Dosyalar

* **`quantum_fraud_detection.ipynb`:** Tüm veri önişleme, klasik model karşılaştırmaları ve Qiskit tabanlı Kuantum SVM (QSVM) eğitim adımlarını içeren, sunuma hazır ana analiz notebook dosyası.

## 🛠 Çalışma Yöntemi

1. **Açıklayıcı Anlatım:** Kod bloklarının yanına ne yapıldığına dair markdown açıklamaları eklenmiştir. Bu sayede sunum anında kodun işleyişi kolayca takip edilebilir.
2. **Yedekleme ve Kaydetme:** Notebook üzerinde başarılı olan ve kararlı çalışan fonksiyonlar, `src/` klasöründeki Python dosyalarına aktarılarak modüler hale getirilmiştir.
