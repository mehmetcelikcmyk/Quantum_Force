## 📖 Dosya İndeksi ve Özetler
* **Yilmazfigen_quantum temeli.pdf:** Kuantum hesaplamanın temel kavramları, kübit yapıları ve kapı modelleri üzerine giriş kaynağı.
* **quantum_finance_optimation.pdf:** Kuantum algoritmalarının finansal portföy veya genel kombinatoryal optimizasyon problemlerine uygulanması.
* **FormulatingandSolvingRoutingProblems...:** Kuantum Tavlama (Quantum Annealing) veya QAOA ile rotalama/lojistik problemlerinin modellenmesi.

### 🛠 Ekip İçin Çalışma Yönergesi:
1. **Raporlama Süreci:** Proje detay ve jüri raporlarını yazarken, metin içinde geçtiğiniz teorik bilgileri doğrudan bu dökümanda yer alan **APA 7** formatındaki künyeleri kullanarak kaynak gösteriniz.
2. **Eksik Kaynak Bildirimi:** Araştırmalarınız sırasında projeye dahil ettiğiniz yeni bir PDF kaynak olursa, dosyayı bu klasöre yükledikten sonra künyesini mutlaka aşağıdaki listeye akademik formatta ekleyiniz.
3. **Bağlantı Kontrolü:** İndirme bağlantısı (orijinal linki) eksik olan çalışmaların kaynak web sitelerini bulduğunuzda tablodaki ilgili alanları güncelleyiniz.
